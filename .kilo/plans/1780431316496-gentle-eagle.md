# Plan: Move theme switcher and logout to sidebar items

## Goal
Move the theme toggle and logout buttons from the `SidebarFooter` into `SidebarNavItem` items within the sidebar navigation.

## Current State
- `src/components/layout/MainLayout.tsx` contains both the theme toggle and logout button in `SidebarFooter`
- Both features already use Redux Toolkit (setTheme action, logoutSuccess, useLogoutMutation)
- `SidebarNavItem` component exists for nav items with NavLink, icon, and label support

## Plan

### 1. Add theme toggle as sidebar nav item
Replace the theme toggle button in `SidebarFooter` with a `SidebarNavItem` that acts as a toggle:
```tsx
<SidebarNavItem onClick={handleThemeToggle} label={currentTheme === 'dark' ? 'Switch to light mode' : 'Switch to dark mode'} icon={<Moon size={16} />} />
```
Or use a custom element that toggles theme on click while keeping nav styling.

### 2. Add logout as sidebar nav item
Replace the logout button in `SidebarFooter` with a `SidebarNavItem`:
```tsx
<SidebarNavItem onClick={handleLogout} label="Log out" icon={<LogOut size={16} />} />
```

### 3. Update SidebarNavItem to support custom onClick
The `SidebarNavItem` currently uses `NavLink` which navigates to routes. For theme toggle and logout, we need `onClick` handler support. Update `SidebarNavItem` to accept an `onClick` prop and conditionally render either `NavLink` (when `to` is provided) or a `<button>` (when `onClick` is provided).

### 4. Clean up SidebarFooter
After moving theme toggle and logout out of the footer, remove or leave `SidebarFooter` empty. Optionally remove the footer elements entirely if not needed.

## Files to modify
- `src/components/layout/SidebarNavItem.tsx` — Add `onClick` support, conditionally render `NavLink` vs button
- `src/components/layout/MainLayout.tsx` — Replace theme toggle and logout buttons with `SidebarNavItem` instances
- `src/components/layout/MainLayout.tsx` — Remove sidebar footer content or clean it up

## Notes
- No new files need to be created
- Theme toggle and logout functionality already exists; only UI placement changes
- Both actions are already dispatched through Redux store
- `SidebarNavItem` needs to support `onClick` prop alongside the existing `to` prop
