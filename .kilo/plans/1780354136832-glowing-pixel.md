# Task Create/Edit Functionality Plan

## Overview

This plan defines the implementation of full create and edit task functionality for Aqua CRM.

## Implementation Phases

### Phase 1: Task Form Enhancements

**Files:**
- `src/views/TaskForm.tsx`
- `src/api/tasksApi.ts`
- `src/types/entities.ts`

**Enhancements:**
- Add subtask support with toggle for subtask creation
- Add dependencies UI with add/remove functionality
- Add validation for title, parent task, and dependencies
- Use RTK Query mutations for create/update operations
- Add loading states during submission
- Add success/error messages

**Validation Rules:**
- Title is required
- Parent task is required for subtasks
- Cannot mix start-to-start and finish-to-finish dependencies
- No circular dependencies

**Success Criteria:**
- [ ] Task form validates all required fields
- [ ] Subtasks can be created with parent task selection
- [ ] Dependencies can be added/removed from form
- [ ] RTK Query mutations are used for create/update
- [ ] Loading states are shown during submission
- [ ] Success/error messages are displayed
