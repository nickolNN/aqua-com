# Plan: Logout Button in Sidebar + Auth Form

## Goal
Add a "Log out" button to the sidebar footer and show the auth (login) form when logged out.

## Current State

1. **Sidebar** (`src/components/layout/Sidebar.tsx`) — Has Sidebar, SidebarHeader, SidebarContent, SidebarFooter components
2. **MainLayout** (`src/components/layout/MainLayout.tsx`) — Uses the sidebar with theme toggle in SidebarFooter
3. **Auth Slice** (`src/stores/authSlice.ts`) — Has `logoutSuccess` reducer that clears user state
4. **Auth API** (`src/api/api.ts`) — Already has `useLogoutMutation` hook
5. **LoginView** (`src/views/LoginView.tsx`) — Login form exists
6. **i18n** — Has logout translation in Spanish

## Plan

### 1. Add logout button to SidebarFooter (MainLayout.tsx)

In `src/components/layout/MainLayout.tsx`, add a logout button to the SidebarFooter alongside the theme toggle.

```tsx
// In the SidebarFooter, add:
import { useLogoutMutation } from '@/api/api';
import { logoutSuccess } from '@/stores/authSlice';
import { LogOut } from 'lucide-react';

// Inside MainLayout:
const [logout] = useLogoutMutation();

const handleLogout = async () => {
  dispatch(logoutSuccess());
  await logout().unwrap();
  localStorage.removeItem('token');
};
```

Add the button next to the theme toggle in the SidebarFooter:

```tsx
<button type="button" onClick={handleLogout} className="flex items-center gap-2 text-sm text-sidebar-foreground hover:text-sidebar-accent-foreground transition-colors">
  <LogOut size={16} />
  <span>Log out</span>
</button>
```

### 2. Add logout i18n string

Add to `src/i18n/translations.ts`:
- English: `"log out"` under the auth section
- Spanish: `"Cerrar sesión"` under auth

### 3. Update SidebarFooter styling

The SidebarFooter already has border-t and p-4 styling. The logout button should follow the same pattern as the theme toggle button.

### 4. Wire up logout

The logout flow:
1. User clicks logout button
2. Dispatch `logoutSuccess` to clear auth state
3. Call `useLogoutMutation` API endpoint
4. Remove token from localStorage
5. Navigate to login page (handled by PrivateRoute redirect)
