# Aqua CRM - Two-Phase Development Plan

## Goal

Split development into two distinct phases:
1. **Phase 1: Frontend with mocked data** — Build the complete UI with mock API layer, enabling full interaction and visual verification before backend implementation
2. **Phase 2: Backend implementation** — Implement the Go/Gin/GORM backend with real data and connect the frontend

## Plan Summary

| Item | Value |
|------|-------|
| Total Phases | 2 |
| Phase 1 | Frontend with Mocked Data (React Compiler + React 19 + Redux + RTK Query + MSW) |
| Phase 2 | Backend Implementation (Foundation, Auth, API Endpoints, Database, Integration) |

---

## Phase 1: Frontend with Mocked Data

### Objective
Build a fully interactive frontend application using React 19 + React Compiler + Redux Toolkit (with RTK Query) and MSW for mocked data, so users can see and test the entire CRM UI before backend implementation.

- [ ] **FE** Step 1.2: Configure Vite build system with proper aliases and path resolution
- [ ] **FE** Step 1.3: Set up React Router with all route definitions (auth, contacts, companies, tasks, activities, dashboard)
- [ ] **FE** Step 1.4: Configure Redux Toolkit store — create base store with reducers, middleware (RTK, thunk, logger), and devtools
- [ ] **FE** Step 1.5: Set up RTK Query with base API endpoint and tags system for cache invalidation
- [ ] **FE** Step 1.6: Create all Redux slices (auth, contacts, companies, tasks, activities, dashboard, search, settings)
- [ ] **FE** Step 1.7: Create all Redux async thunks for slice actions (fetch, create, update, delete)
- [ ] **FE** Step 1.8: Set up RTK Query API definitions with endpoints for all resources
