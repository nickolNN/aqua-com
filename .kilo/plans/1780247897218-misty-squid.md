# Sidebar Dashboard Layout

## Goal
Make the sidebar fixed (doesn't scroll with content), add borders, and give it a dashboard-like appearance.

## Current State
- **MainLayout.tsx** uses a `<div className="flex min-h-screen">` layout with:
  - Sidebar aside (`w-64 min-h-screen`)
  - Content area (`flex-1`)
- Sidebar components use Tailwind with `bg-sidebar` and `text-sidebar-foreground` color tokens
- `SidebarContent` component has `overflow-y-auto` for internal scrolling

## Changes

### 1. MainLayout.tsx (`src/frontend/src/components/layout/MainLayout.tsx`)

Update the sidebar wrapper to be sticky and add borders:

```jsx
// BEFORE:
<aside className="w-64 min-h-screen bg-sidebar text-sidebar-foreground">

// AFTER:
<aside className="sticky top-0 h-screen w-64 flex flex-col border-r bg-sidebar text-sidebar-foreground">
```

This ensures:
- `sticky top-0` - sidebar stays fixed at the top, won't scroll with content
- `h-screen` - full viewport height (replaces `min-h-screen`)
- `border-r` - adds right border
- `flex flex-col` - enables flex column layout for header/content/footer stacking

Also update the content area wrapper to be sticky to contain the header:

```jsx
// BEFORE:
<div className="flex-1">
  <Header title="Aqua CRM">
  ...
  <main className="p-6">

// AFTER:
<div className="flex-1 flex flex-col min-h-screen">
  <Header title="Aqua CRM">
  ...
  <main className="flex-1 p-6">
```

This ensures the header stays at the top of the content area while content scrolls inside `<main>`.

### 2. Sidebar.tsx (`src/frontend/src/components/layout/Sidebar.tsx`)

Add border styling to the Sidebar component:

```jsx
// BEFORE:
className={cn('h-full bg-sidebar text-sidebar-foreground', className)}

// AFTER:
className={cn('h-full bg-sidebar text-sidebar-foreground border-r border-sidebar-border', className)}
```

This adds a consistent border color using the existing `--sidebar-border` CSS variable.
