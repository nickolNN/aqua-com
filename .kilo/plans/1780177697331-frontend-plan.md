# Aqua CRM - Frontend Development Plan

## Goal

Build the complete frontend application with mocked data layer, enabling full UI interaction and visual verification before backend implementation.

## Plan Summary

| Item | Value |
|------|-------|
| Total Steps | 10 |
| Tech Stack | React 19 + TypeScript + React Compiler + Redux Toolkit + RTK Query + MSW + Tailwind CSS + Vite |

---

## Steps

### Step 1: Frontend Infrastructure Setup
- [ ] **FE** Step 1.1: Set up React 19 + TypeScript + React Compiler + Redux Toolkit (with RTK Query) + Tailwind CSS + Vite
- [ ] **FE** Step 1.2: Configure Vite build system with proper aliases and path resolution
- [ ] **FE** Step 1.3: Set up React Router with all route definitions (auth, contacts, companies, tasks, activities, dashboard)
- [ ] **FE** Step 1.4: Configure Redux Toolkit store — create base store with reducers, middleware (RTK, thunk, logger), and devtools
- [ ] **FE** Step 1.5: Set up RTK Query with base API endpoint and tags system for cache invalidation
- [ ] **FE** Step 1.6: Create all Redux slices (auth, contacts, companies, tasks, activities, dashboard, search, settings)
- [ ] **FE** Step 1.7: Create all Redux async thunks for slice actions (fetch, create, update, delete)
- [ ] **FE** Step 1.8: Set up RTK Query API definitions with endpoints for all resources
- [ ] **FE** Step 1.9: Define TypeScript types/interfaces for all API entities (Contact, Company, Task, Activity, User, etc.) in a shared types file

### Step 2: Mock Data Infrastructure (Centralized Mock Data)
- [ ] **FE** Step 2.1: Create centralized mock data directory (`src/mock-data/`)

- [ ] **FE** Step 2.3: Create mock data generators for each entity (with realistic sample data)
