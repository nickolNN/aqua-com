# Step 6: Auth API Endpoints

6.1 Register endpoint: `POST /api/v1/auth/register`
6.2 Login endpoint: `POST /api/v1/auth/login` (returns JWT + refresh token)
6.3 Refresh endpoint: `POST /api/v1/auth/refresh`
6.4 Logout endpoint: `POST /api/v1/auth/logout`
6.5 Profile endpoint: `GET /api/v1/auth/profile`
