## Behavioural guard in the detail modal — verified safe

`src/components/tasks/TaskDetailModal.tsx:62`:
`onOpenChange={(open) => { if (!open && !showDeleteConfirm) onCancel(); }}`.
While the nested ConfirmDialog is open, its portaled panel is outside the
outer dialog's content, so a click on the confirm button would fire the
outer dialog's `onInteractOutside`; the guard swallows close requests until
`showDeleteConfirm` is false. Walked all paths:

- confirm click → `handleDelete` runs, `onDeleted` unmounts the modal — delete executes;
- Cancel / Esc on the confirm dialog → `showDeleteConfirm` flips false, outer stays open;
- delete failure → error shown in the outer dialog, confirm stays open, retry/Cancel both work;
- worst case (outer close fires while confirm is open) → modal closes with **no** deletion, because `handleDelete` only runs on the explicit confirm-button click. No data-loss path.
