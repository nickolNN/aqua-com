# Iteration 5 — Resolve

## What was changed

The Review step found that the shipped screenshot script's after-run board
pinning silently fails: the `addInitScript` callback in
`scripts/capture-screenshots.mjs` closed over the Node-side const
`TASKS_STORAGE_KEY`, which does not exist in the browser where Playwright
re-evaluates the stringified function — a silent `ReferenceError` meant the
pin never landed, so every `after` run seeded a fresh random board and the
ticket's before/after evidence was confounded (the same root cause already
fixed in `scripts/verify-consistency.mjs`).

Fix (one word, plus a NOTE comment matching the verifier):

- `scripts/capture-screenshots.mjs` — the init script body now uses the
  literal `'mock_data_tasks'` key instead of the Node-side
  `TASKS_STORAGE_KEY` identifier, so the pin lands in the browser.

No app (`src/`) edits, no config changes, no manifest changes.

## What was verified

1. **Pin lands** — a one-off Playwright check (script removed after the run)
   launched a context with the fixed init script, logged in, and compared the
   browser's `localStorage['mock_data_tasks']` against
   `docs/screenshots/.mock-state.json`: byte-identical, 10/10 tasks, first
   card "Update documentation" (the pinned board's first task).
2. **After shots re-captured** — `node scripts/capture-screenshots.mjs after`
   re-took all 11 after/ PNGs with the pin active (log: "Seeded board pinned
   from docs/screenshots/.mock-state.json (10 tasks)").
3. **Before/after boards now match** — ImageMagick `compare -metric AE` on
   all 11 before/after pairs:
   - 8 pairs **byte-identical (0 differing pixels)**: board-light,
     board-dark, login-light, login-dark, quick-add-open,
     task-detail-modal, task-detail-modal-dark, delete-confirm-dialog —
     the board and every unfixed screen render identically, proving the
     after run shows the exact same board as the before run.
   - 3 pairs differ by a small amount, exactly the modals carrying the UI
     fixes: task-create-modal (4036 px),
     task-create-modal-select-open (3609 px), task-edit-modal (4054 px) —
     ~0.2% of the canvas, below the 20k–127kpx same-board anti-aliasing
     baseline and orders of magnitude below the 282k–438kpx board
     mismatch measured before the fix.
4. **Local self-checks** — `node --check scripts/capture-screenshots.mjs`
   passes; `pnpm lint` clean (eslint covers ts/tsx; the .mjs script is
   covered by `node --check`); `docs/screenshots/.mock-state.json`
   unchanged (md5 `906c7c92a4c0abd0c4a9026d5df31ddf`).
